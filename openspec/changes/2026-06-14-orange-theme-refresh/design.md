## Context

仪表盘的视觉主色目前分散在 `src/App.vue`、`src/assets/main.css`、图表配置和少量组件样式里。
如果只改单一入口，页面会出现“按钮是橙色、选中态还是蓝色”的割裂感。

## Goals / Non-Goals

**Goals:**
- 将全局主色统一到橙色系。
- 保持中性色背景、卡片层级和语义色不变。
- 让主按钮、侧边栏高亮、焦点环和关键图表颜色看起来是同一套品牌色。

**Non-Goals:**
- 不重做布局。
- 不调整业务文案。
- 不替换成功、失败、告警等语义色。

## Decisions

- 以 `src/App.vue` 中的 Naive UI `primaryColor` 作为主品牌色入口。
- 以 `src/assets/main.css` 中的 CSS 变量作为页面级强调色入口。
- 仅修正少量直接写死的蓝色值，避免旧主色残留。
- 用一个轻量单测锁定橙色主题令牌，避免后续回退。

## Risks / Trade-offs

- 主题值分布在 CSS 和 TypeScript 两处，需要保持数值一致。
- 图表首色改成橙色后，多个数据系列的区分度会更依赖次级颜色。
