## Context

上一个 change 已经把 Ollama 家族的模型名称输入改成自由输入，但
用户界面仍然缺少明确的语义提示。现在的字段对所有离线节点都长得很
像，用户需要额外推断“哪些节点可以随便填 provider model”。

## Goals / Non-Goals

**Goals:**
- 在 Ollama 家族节点上增加清晰、非侵入式的提示文案。
- 保持现有字段、校验和提交数据结构不变。
- 让用户在表单里直接知道这不是固定下拉选择，而是自由输入项。

**Non-Goals:**
- 不修改后端。
- 不改变 PaddleOCR 或在线节点的提示文案。
- 不增加新的表单字段或新的模型类型枚举。

## Decisions

- 使用现有的 Ollama family 判断复用提示显示条件。
- 提示文案放在输入框下方，避免修改标签长度导致表单视觉噪音过大。
- 文案只在 Ollama family 离线节点上显示，其他节点保持原样。

## Data Flow

1. 用户打开 OCR 节点表单并选择 Ollama family 模型。
2. 表单判断当前节点属于 Ollama family。
3. 模型名称输入框下方显示提示文案。
4. 用户按提示填写真实 provider model。

## Risks / Trade-offs

- 提示文案过长会让表单更拥挤，因此保持一句话、单行可读。
- 如果未来还要区分更多家族，可能需要更通用的提示组件；这次不做。

## Testing

- 新增组件测试，确认 Ollama family 节点显示提示文案。
- 新增组件测试，确认 PaddleOCR 节点不显示该提示。
- 运行组件测试和前端构建，确认样式和模板没有回归。
